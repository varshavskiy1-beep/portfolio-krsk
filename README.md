# portfolio_krsk

Кабинет бумажных торговых ботов (paper only). Данные — `public/data/latest.json` (`equity_ro.v1`).

Публичный сайт: https://portfolio-krsk.vercel.app

OG-превью для Telegram: `public/og-cover.jpg` (1200×630, JPEG q≈85; PNG остаётся как запасной файл). Счёт с максимальной прибылью в деньгах: equity − seed, без FX. Теги `og:*` лежат в сыром `index.html` (`og:image:type`, `og:image:secure_url`, `og:site_name`, `og:locale`). После деплоя кэш Telegram можно сбросить через https://t.me/webpagebot; надёжная проверка — переслать ссылку в Saved Messages (ответ webpagebot часто без карточки даже после успешного обновления).
