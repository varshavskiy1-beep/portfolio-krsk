# Grail B20 @ 3x — канон стратегии для сайта

**Кому:** веб-дизайнер / копирайтер страницы стратегии  
**Стратегия:** `grail_b20_3x`  
**Рынок:** бессрочные фьючерсы OKX в USDT (USDT-SWAP)  
**Статус на сайте:** paper / тестирование на биржевом контуре — **не** обещать «живой боевой счёт для всех» и **не** продавать CAGR как гарантию  
**Дата канона теста:** 2026-09-04  
**Цифры дашборда:** `dashboard_card.json`, `dashboard_metrics.json` в этой же папке  

Этот файл — полное описание того пресета, который тестировали. Параметры ниже — закон страницы. Если на сайте написано иначе, чем здесь, править сайт, а не стратегию.

## 1. Одной фразой

Робот держит **одну** позицию из корзины из **20** крипто-перпов (без биткоина и других mega-cap), входит только когда старший сигнал подтверждён на пятиминутном графике с уверенностью не ниже **55%**, размер — почти весь доступный баланс с плечом **3**, стоп не дальше **12%** от входа, цель не хуже чем **1 к 1** к риску.

---

## 2. Для кого и зачем (тон сайта)

Можно писать:

- стратегия следует импульсным движениям на часовом горизонте;
- выбирает один инструмент из узкой корзины альтов и акций-прокси (MSTR, SPCX);
- жёстко ограничивает глубину стопа и требует, чтобы потенциальная прибыль была не меньше риска;
- результаты ниже — из исторического прогона на замороженных сигналах, не обещание дохода.

Нельзя писать:

- «гарантированная доходность», «без риска», «всегда 1000% в год»;
- что робот торгует биткоин, эфир, SOL, BNB или XRP — их в каноне нет;
- что плечо 5× — продукт снят;
- что это уже массовый Live-продукт. На момент канона — paper / ограниченный pre-live контур.

## 3. Как это работает простыми словами

### Шаг 1. Смотрит два таймфрейма

- **Час (H1)** — основной план: куда смотрит рынок (вверх / вниз / ждать).
- **Пять минут (M5)** — подтверждение. Без жёсткого подтверждения на M5 вход запрещён.

### Шаг 2. Оценивает уверенность

Вход только если уверенность сигнала **не ниже 0.55** (55%) и защита (стоп/цель) собрана корректно. Слабые идеи отбрасываются.

### Шаг 3. Выбирает один инструмент

Из 20 тикеров выбирается **один** лучший actionable-сигнал. Одновременно открытых позиций — **не больше одной**. Уже открытая позиция важнее «чуть более красивой» идеи на другом тикере: ради неё робота не дёргают.

### Шаг 4. Входит на следующем часе

Сигнал считается на **закрытии** часовой свечи. Сделка исполняется по **открытию следующей** часовой свечи. Так устроен тест: без подглядывания в будущее.

### Шаг 5. Режет убыток и фиксирует прибыль

- Стоп из сигнала, но **не дальше 12%** от цены входа.
- Цель подтягивается так, чтобы отношение прибыль/риск было **не хуже 1.0** (если цель была слишком близко — её растягивают, а не отменяют вход).
- Дополнительно: фиксация по капиталу около **12%**, «замок прибыли» после роста **7.5%** (откат не больше **25%** от пиковой прибыли), выход по структуре рынка при прибыли от **3.75%**.
- Если план развернулся в обратную сторону — позиция закрывается.

### Шаг 6. Размер позиции

Свободный капитал режется буфером **57%** (в деле остаётся около **43%** счёта), затем умножается на плечо **3**.  
Итоговый номинал позиции ≈ **1.29 × размер счёта**, а не «три полных счёта». Маржа — **cross** (общая по счёту).

## 5. Правила риска (короткий блок для UI)

| Правило | Значение | Как объяснить посетителю |
|---|---|---|
| Плечо | 3× | Усиливает и прибыль, и просадку |
| Позиций сразу | 1 | Не раскидывает счёт на десять идей |
| Буфер капитала | 57% | Часть счёта специально не пускает в сделку |
| Макс. стоп | 12% от входа | Убыток на сделку ограничен по расстоянию стопа |
| Мин. R:R | 1.0 | Цель не мельче риска |
| Уверенность | ≥ 55% | Слабые сигналы пропускает |
| Подтверждение | M5 обязательно | Часовой план без короткого подтверждения не торгуется |
| Режим маржи | cross | Общая маржа счёта |
| Смена доли от «режима эквити» | выкл. | Не прячет риск «умным» уменьшением доли |

Плечо **5× в продукт не входит**.

## 6. Результаты теста (что можно показать цифрами)

Источник: замороженный бэктест книги «1× против 3×», дата **2026-09-04**.  
Исполнение в тесте: сигнал на закрытии часа → вход на открытии следующего; комиссия и проскальзывание заложены; эквити считается каждый час.

### Главная карточка — вся история, плечо 3×

| Показатель | Значение | Пояснение для сайта |
|---|---:|---|
| CAGR | **1029.7%** | Годовая доходность в тесте; на короткой истории сильно шумит, не обещание |
| Макс. просадка | **47.9%** | Худший спад капитала от пика |
| Profit factor | **1.909** | Сумма прибылей / сумма убытков |
| MAR (CAGR / просадка) | **21.51** | Грубый «доход на единицу боли» |
| Сделок | **468** | Число завершённых сделок в книге |
| Sharpe | нет в отчёте | Не публиковать выдуманный Sharpe |

### Сравнение окон на плече 3× (обязательно показать честно)

| Период | CAGR | Макс. просадка | Profit factor | Сделок |
|---|---:|---:|---:|---:|
| Вся история | 1029.7% | 47.9% | 1.909 | 468 |
| 2-я пол. 2024 | 26.2% | 43.1% | **1.074** | 113 |

Смысл для текста: в удачные годы стратегия выглядит очень сильно, но во **второй половине 2024** на плече 3× край почти исчезает (profit factor около единицы). Это не прятать.

### Для справки — то же без плеча (1×)

На полной истории: CAGR **100.2%**, просадка **22.0%**, PF **1.741**, 241 сделка.  
На сайте основной продукт — **3×**; блок 1× можно дать как «как выглядело бы без плеча».

## 7. Что происходит на живом контуре (не путать с бэктестом)

| Режим | Что это | Можно ли писать на сайте |
|---|---|---|
| Paper | Бумажный прогон / smoke с теми же правилами | «бумажный режим / симуляция» |
| Pre-Live | Подключение к бирже на малом счёте после аудита | «ограниченный боевой контур», без обещания масштаба |
| Live для всех | Не статус канона | Не утверждать |

Проверка paper-smoke в репозитории подтверждает только каузальность (сигнал раньше исполнения), это **не** источник цифр CAGR на сайте.

## 8. Словарь для подписей на макете

| Термин в коде | Как писать людям |
|---|---|
| USDT-SWAP | бессрочный фьючерс в долларах |
| m5hard | вход только с подтверждением на 5 минутах |
| confidence ≥ 0.55 | уверенность сигнала не ниже 55% |
| R:R ≥ 1 | цель не меньше размера стопа |
| stretch_tp | если цель слишком близко — отодвигаем цель, а не отменяем сделку |
| cross | общая маржа по счёту |
| buffer 0.57 | запас капитала, который не идёт в сделку |
| Close t → Open t+1 | решили на закрытии часа, вошли на открытии следующего |
| MaxDD | максимальная просадка |
| Profit factor | во сколько раз прибыли перекрыли убытки |
| MAR | доходность, делённая на просадку |

## 9. Готовый короткий текст (можно почти как есть)

**Заголовок:** Grail B20 · плечо 3×  

**Подзаголовок:** Одна позиция из корзины 20 крипто-перпов. Вход по часовому плану только с подтверждением на 5 минутах.

**Абзац:**  
Стратегия сканирует узкую корзину ликвидных бессрочных контрактов на OKX — без биткоина и других самых крупных монет. Робот открывает не больше одной сделки: сигнал на закрытии часа, исполнение на открытии следующего. Стоп ограничен 12% от входа, цель не слабее риска один к одному, в сделку идёт часть капитала с плечом три после резерва. Исторический прогон на полной выборке показал высокую доходность при просадке около 48%; во второй половине 2024 край на плече 3× был слабым — это часть честной картины, а не исключение.

**Дисклеймер (обязателен рядом с CAGR):**  
Цифры — результат исторического теста на замороженных сигналах. Прошлая доходность не гарантирует будущую. Возможна потеря большей части депозита.
